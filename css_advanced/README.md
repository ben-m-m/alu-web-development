# CSS Advanced Project

## Project Overview
This project builds on the previous **HTML Advanced** task by focusing entirely on the page styling and CSS. The base page structure is already provided in `index.html`, copied from `html_advanced/index.html`, and your goal is to match the design from the provided Figma file.

## Objectives
- Complete the CSS styling for the `css_advanced` page.
- Ensure all previous HTML advanced tasks are fully completed before working on CSS.
- Use the Figma design source as the reference for layout, typography, colors, spacing, and responsiveness.
- Keep the HTML structure intact and apply styles with clean, maintainable CSS.

## Files
- `README.md` - this project overview and instructions.
- `index.html` - main HTML page, copied from the advanced HTML version.
- `styles.css` or equivalent CSS file(s) should be added to implement the design.

## Requirements
- Recreate the page design using CSS only.
- Ensure the page looks close to the Figma layout on desktop and smaller screens.
- Round float values if needed for clean CSS values.
- Include responsive behavior and a polished visual hierarchy.
- Use semantic HTML already present in `index.html`.

## Notes
- If you do not already have the design fonts installed, use the provided font files from the Figma notes.
- The Figma illustration may contain pixel values with decimals; it is fine to round them for your implementation.
- Verify that the page is complete and styled before submitting.

## Recommended workflow
1. Open `index.html` in a browser.
2. Create a CSS file and link it from the HTML header.
3. Apply page-level layout, typography, and color styles.
4. Add responsive rules for smaller screen widths.
5. Compare the result against the Figma design and adjust spacing and alignment.

## Submission
- The final result should be in the `css_advanced` directory.
- Make sure `index.html` is the same advanced HTML structure and that CSS completes the design.
